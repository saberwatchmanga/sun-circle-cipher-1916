# Reproduction scope and release hygiene

The release uses fixed small text inputs and standard-library scripts; it does not depend on personal filesystem paths, local sibling repositories, credentials or model services. `primary107_vs_raw591.tsv` pins only the107 glyph/number assignments used in the prior comparison. The portable reproduction rebuilds kana and Roman forms from those fixed assignments, recomputes the global letter alignment and compares every output cell. It does not independently re-derive the historic glyph-to-number codebook or verify the physical print.

The eight signature-word comparison pins prior boundaries and worksheet numbers and reproduces the original seed20261007,100shuffle control. Positive count5, control mean0.72 and maximum5 are retained without uniqueness claims. Formula inversion is tested across1–9200; this is deterministic implementation validation. Round3 tests retain both e branches and compare incomplete versus complete codeword windows. Round4 verification checks coverage structure/counts, not the correctness of every image classification.

The full evidence ledger is included as a pinned dated snapshot. It is not regenerated by an undistributed visual workflow. No full speculative plaintext is presented as a verified result. Large language-model/search corpora, source scans, unrelated candidates, original private conversations, personal absolute paths, machine configuration, credentials and git history from unrelated repositories are excluded. Old local reports and their hashes are preserved; selected relative origin identities and hashes record what was included or summarized.

Before publication the package must pass all three documented commands in a fresh copy, hash checks and a staged-file scan. A clean git history is created solely for this package, with a repository-local public noreply identity. No inherited credential/config files or symlinks are allowed. The original lab is never the git repository root.
