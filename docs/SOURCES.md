## Reproduction permissions decision (10 October2026)

The Commons file page was successfully checked and labels the1916 book and mechanical scan public domain. We include only the manually transcribed107-character historical passage; no book PDF or image is uploaded. This preserves a concise checkable witness without redistributing an entire publication.

JACAR's [About Usage of Document Images](https://www.jacar.archives.go.jp/aj/www/doc/en/) was located; cloud access returned403, so detailed terms were not independently established in this publication pass. Public viewing does not by itself establish unrestricted image redistribution rights. **All JACAR PDFs, worksheet crops, contact sheets and downloaded catalogue HTML are excluded.** Source reference numbers, our research transcriptions, coordinates, SHA256 values and original links are retained. Contemporary content, present-day scan rights and project-authored code/analysis are distinct.

No blanket third-party license is asserted. See RIGHTS.md. Other modern publications and external full codebooks are linked rather than uploaded. No paid material, account, email or permission request was involved.

## Retrieve privately for visual rechecking

Use the cited institution's public catalogue/viewer, obey its current terms, and stop if access is refused. Save downloads under ignored `sources/`. Compare SHA256 with the pinned values; changed downloads should be investigated rather than treated as the same image. The four round4 PDF URLs and hashes are in `data/round4/download_manifest.json`. Locate the target by its catalogue ID and compare the page/frame mappings above. Obtain the1916 book from its Commons file page and inspect PDF26; no source retrieval is necessary for the offline computational checks. Retrieval availability is not guaranteed and is separate from those tests.
